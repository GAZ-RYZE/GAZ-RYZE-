GAZ-RYZE 🚀

Современный веб-проект, созданный с использованием HTML, CSS и JavaScript.

Проект сочетает минималистичный дизайн, интерактивные элементы и адаптивную структуру, делая интерфейс удобным и приятным для пользователя.

⚡ Особенности

- 🎨 Современный дизайн
- 📱 Адаптивная вёрстка
- ⚡ Быстрая работа интерфейса
- 🧩 HTML + CSS + JavaScript
- ✨ Интерактивные элементы
- 📂 Простая и понятная структура проекта

🛠️ Технологии

HTML5 · CSS3 · JavaScript
